# SpecTrace

Requirements traceability for teams that keep Markdown specifications
next to their code. Links spec items to source symbols, keeps the links
under human review, and detects drift as the repository evolves.

- `specs/` — the specification vault (CLI spec, product spec, plans)
- `packages/core` — the analysis engine
- `packages/cli` — command-line tool (CPSC 597 capstone deliverable)
- `apps/studio` — desktop knowledge-base app (added in a later phase)

A Ghost Harbor LLC project. Capstone context: CSUF CPSC 597, 2026–2027.
